# Project Statement

## Project Title

Attendance Calculator

## Problem Statement

Students often find it difficult to keep track of their attendance percentage for different subjects. Manual calculations can take time and may lead to mistakes.

The Attendance Calculator provides a simple command-line solution to store attendance data, calculate percentages, and help students understand how many classes they can skip or need to attend.

## Scope

The project manages subject-wise attendance information and performs attendance-related calculations.

## Target Users

- College students
- School students
- Students who want to track attendance easily

## High-Level Features

- Add subjects
- Update attendance
- View attendance percentage
- Calculate classes that can be skipped
- Calculate classes required to reach the attendance limit
- What-if attendance calculation
- Change required attendance percentage
- Delete subjects
- JSON-based data storage

## Technologies

- Python
- JSON
- File Handling
- Mathematical Calculations
- Command Line Interface
