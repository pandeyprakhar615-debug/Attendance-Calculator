Attendance Calculator
Overview

Attendance Calculator is a Python-based command-line application that helps students manage and calculate their attendance for different subjects.

The application stores subject-wise attendance data and provides useful calculations such as current attendance percentage, classes that can be skipped, and classes that need to be attended to reach the required percentage.

Features
Add new subjects
Update attendance
View attendance of all subjects
Calculate current attendance percentage
Check how many classes can be skipped
Calculate how many classes need to be attended
What-if attendance scenario
Change required attendance percentage
Delete subjects
Store data using JSON
Input validation and error handling
Technologies Used
Python
JSON
File Handling
Mathematical Calculations
Command Line Interface (CLI)
How to Run
Install Python.
Open the project folder in VS Code.
Open the terminal.
Run:

python main.py

Project Modules
main.py — controls the main application
storage.py — saves and loads attendance data
calculator.py — performs attendance calculations
subjects.py — manages subjects and attendance
menu.py — displays the application menu
